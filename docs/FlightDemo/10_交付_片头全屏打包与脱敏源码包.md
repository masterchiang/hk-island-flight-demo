## 1. 片头 LOGO（`LOGO.jpg`，保持 2.5 秒后进入 DEMO）

**新增脚本**：`Assets/_FlightDemo/Scripts/DemoStartup.cs`，挂在场景 `Systems` 节点上。
Unity 官方启动画面不受影响，仍在其之前播放。

实现方式：运行时在 `Systems` 下建一个 `FlightDemo_Logo_Canvas`
（`ScreenSpaceOverlay`、**sortingOrder = 500**，高于 HUD 的 100）：

| 元素 | 说明 |
|---|---|
| `Backdrop` | 全屏纯黑 `Image`，`raycastTarget` 默认开启 → 片头期间挡住误点击 |
| `Logo` | 全屏拉伸的 `RawImage` + `AspectRatioFitter(FitInParent)`，**等比不失真** |

参数（Inspector 可调）：

- `holdSeconds = 2.5`（完全显示时长）、`fadeSeconds = 0.3`（淡出）
- `logoResourcePath = "LOGO"`，同时有 `logoTexture` 序列化字段（场景已绑定）
- `pauseFlightDuringLogo = true`：片头期间调用 `FlightController.SetPaused(true)`，DEMO 从航线 0% 开始
- `logoMaxScreenFraction = 1`：铺满屏幕（按比例内缩可留边）

计时用 `Time.unscaledTime`，不受暂停影响；暂停动作放在 `Update` 里等
`FlightController.Ready` 之后再执行，避免被它自己的 `Start()` 覆盖。

**实测**（4K Game 视图 3840×2160）：LOGO 矩形 3840×2143 → 宽高比 **1.792**，与原图一致；
`flightPaused=True`、进度 0.008%；`unscaledTime` 0.47 → 3.41 消失，**约 2.94 s ≈ 2.5 + 0.3**；
结束后 `flightPaused=False` 且进度开始推进。截图 `output/FlightDemo/startup_logo_splash.png`、
`startup_demo_after_logo.png`。

### LOGO 纹理导入设置

`maxTextureSize 4096`、`CompressedHQ`、`npotScale None`（**保持宽高比，不做 POT 吸附**）、
关 mipmap、`alphaSource None`、sRGB。

> 坑：编辑器里 `Texture2D.format` 与 `Profiler.GetRuntimeMemorySizeLong` 会显示成
> **未压缩**（RGB24/RGBA32，71 MB），即使显式指定 DXT1 也一样——这是 Unity
> 编辑器加载纹理的固有行为，**不代表导入设置没生效**。构建后实测
> `HKFlightDemo_Data/resources.assets` 仅 9.67 MB，证明 4096×2286 的 LOGO
> 确实以 BC 压缩进了包。

## 2. 全屏无边框 + 分辨率自适应

**PlayerSettings**（已落盘，`ProjectSettings.asset` 可见）：

| 项 | 值 |
|---|---|
| `fullscreenMode` | `1` = **FullScreenWindow**（无边框全屏） |
| `defaultIsNativeResolution` | `1` |
| `defaultScreenWidth / Height` | 1920 × 1080（窗口化时的默认值） |
| `resizableWindow` / `allowFullscreenSwitch` / `runInBackground` / `visibleInBackground` | 均 `1` |

另在 `DemoStartup.ApplyBorderlessFullscreen()` 里加了**运行时兜底**：
启动时若不在 `FullScreenWindow` 或分辨率不等于显示器原生分辨率，
就 `Screen.SetResolution(Display.main.systemWidth, Display.main.systemHeight, FullScreenMode.FullScreenWindow)`。
该逻辑用 `#if !UNITY_EDITOR` 包住，**只在打包后的 Player 生效**，不改动编辑器 Game 视图。

分辨率自适应：HUD 用 `CanvasScaler`（1920×1080 参考、`matchWidthOrHeight 0.5`），
相机自适应，片头用 `AspectRatioFitter`，均已按 3840×2160 实测。

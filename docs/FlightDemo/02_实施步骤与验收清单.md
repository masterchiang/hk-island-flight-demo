# 香港岛 J-20 飞行 DEMO｜简版制作步骤

日期：2026-10-01

只完成本次能力展示，不划分灰盒版、正式版或后续迭代。占位模型只是中间制作工具。

## 制作顺序

| 步骤 | 要做什么 | 做到什么程度 |
|---|---|---|
| 1. 搭场景 | 在现有 Unity 工程中新建展示场景，放简化岛、海面、代理飞机和灯光 | 能看清飞机、岛屿和演示范围 |
| 2. 自动飞行与镜头 | 设置一条闭合环岛航线，完成低速巡航、第三人称跟随和自由观察 | 一启动就能自动展示，镜头平稳 |
| 3. 手动与保护 | 增加解锁驾驶、机体提前检测、自动扶平拉升/外转、海面和边界限制 | 能亲自操作，也不能飞进建筑保护区 |
| 4. UI 与复位 | 加入解锁、复位、暂停、退出按钮，显示状态与必要提示 | 操作简单，任何时候都能回到初始展示状态 |
| 5. 接入模型 | 放入用户提供的香港岛和 J-20，校准比例、朝向、航线、保护体和镜头 | 场景和飞机达到本次展示效果 |
| 6. 展示打磨 | 调光照与画面流畅度，在展示电脑上试运行，打包并写简短按键说明 | 得到一个稳定、可直接演示的 DEMO |

模型未到位前可以完成步骤 1–4，不必停工等待。接入模型后重新检查保护是否覆盖山体、建筑和完整机身。

## 只保留必要检查

以下是待执行检查，不代表功能已经完成：

- [ ] 自动环岛能连续跑完，航线接头没有明显跳动。
- [ ] 相机自由观察不改变飞机航向，解锁后手动控制正常。
- [ ] 从正面、侧面和上方接近保护区，飞机都不会穿入；最高允许速度也检查一次。
- [ ] 海面和各方向边界限制有效，危险情况下能够复位。
- [ ] 连续复位、暂停再继续、切出窗口再回来，不出现失控或界面卡住。
- [ ] 接入本次模型后，在展示电脑上完整演示至少十分钟，退出按钮正常。

不建立大规模自动化测试体系，不做复杂版本管理流程；但发现影响演示的明显错误必须修掉。

## 交付内容

- 本次 DEMO 的 Unity 场景与脚本。
- 可直接运行的 Windows 演示程序。
- 一页以内的操作说明。
- 可选：一段展示录屏，供发送或现场备用。

**优先级：能展示 → 好操作 → 画面出效果 → 演示稳定。不要为了“框架完整”增加本次用不上的功能。**

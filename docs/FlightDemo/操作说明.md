# 飞行 DEMO｜操作说明

## 打开与运行

- Unity 场景：`<PROJECT_ROOT>\My project (1)\Assets\_FlightDemo\Scenes\HKFlight_Demo.unity`。打开后点击 Play，进入自动环岛巡航。
- Windows 演示包预计位置：`<PROJECT_ROOT>\output\FlightDemo\WindowsDemo\HKFlightDemo.exe`。**是否构建成功请以开发进度记录为准；不能只凭这个路径就认为文件已生成。**
- 看不到 UI 时先确认已进入 Play Mode。HUD 是运行时生成，不需要在编辑模式手工补建 Canvas。

## 操作

| 输入 | 功能 |
|---|---|
| 鼠标右键拖动 | 自由观察飞机，不改变飞行方向 |
| 鼠标滚轮 / C | 镜头远近 / 回到尾随视角 |
| 解锁按钮 / Tab | 解锁驾驶；手动状态下再按则复位回自动巡航 |
| W / S | 压低 / 抬高机头 |
| A / D | 左 / 右转向 |
| Shift / Ctrl | 加速 / 减速 |
| 一键复位 / R | 恢复起点、速度、姿态、镜头和自动巡航 |
| 暂停 / Esc | 暂停；弹窗打开时 Esc 先关闭该窗口 |
| 帮助 / F1 | 查看按键与保护说明 |
| 退出 | 确认后退出程序；Editor 内仅停止 Play Mode |

切出窗口会暂停飞行。回来后点击“继续飞行”或按 Esc；若键盘无响应，先点击 Unity Game 视图。

保护一直开启，不会因为解锁而关闭。接近保护区会自动扶平、拉升、向外转向；无安全路线、接近海面或越界时可能自动复位。

## 当前边界

- 采用街机运动学，不是 J-20 真实气动模拟。
- 保护区为保守椭圆柱，不是逐楼碰撞；顶部之上留足机体净空可以安全飞越。
- 原 J-20 模型含两张缺失图片引用，列表见同目录《素材署名与缺失项.md》。
- 中文 UI 使用 Windows 自带雅黑字体。场景光照、海面和后期尚未声称完全复现 Blender 渲染。

# 香港岛 J-20 飞行 DEMO｜简版设计方案

日期：2026-10-01

## 1. 项目定位

这是一个一次性的技术与能力展示 DEMO，也就是“投名状”，不是准备长期运营的游戏产品。

目标是让观看者快速看到三件事：**香港岛场景的视觉效果、J-20 飞行与镜头表现、可操作且稳定的交互能力。**

只围绕这次展示制作，不规划正式版、版本迭代或通用框架。本次修改仅调整设计文档，尚未制作运行场景和脚本。

## 2. 展示流程

**启动即自动环岛 → 自由转动镜头欣赏场景 → 点击解锁亲自驾驶 → 靠近岛内触发自动保护 → 一键复位继续展示。**

主打第三人称观光体验。飞行采用容易操控的街机方式，不模拟真实 J-20 气动、航电或起降。

## 3. 必须做的内容

| 内容 | 简单做法 |
|---|---|
| 自动环岛 | 一条预设闭合航线，飞机低速、平滑地循环飞行 |
| 第三人称观察 | 鼠标右键拖动观察，滚轮调节远近，镜头不影响飞机航向 |
| 解锁驾驶 | 一个按钮切换手动，键盘控制方向、抬头低头和速度 |
| 岛内保护 | 用覆盖岛内山体和建筑的不可见保护体，接近时自动扶平、拉升并向外偏转 |
| 边界限制 | 设置活动范围和高度上限，到达边界自动回到起点 |
| 基础 UI | 解锁驾驶、一键复位、暂停、退出；显示模式、速度、高度和保护提示 |

为控制工作量，**恢复自动环岛直接使用“一键复位”**，不额外制作自动寻找返回航线的功能。

### 保护与复位的底线

- 保护始终开启，解锁驾驶不能关闭保护。
- 提前检查完整飞机的移动空间，不等撞到空气墙才抬头。
- 无法安全避开时，直接复位，不允许继续进入保护体；海面也设置最低飞行高度。
- 复位同时恢复飞机位置、姿态、速度、镜头和自动巡航状态。
- 保护体随本次地图的实际高度设置。默认低空禁止进入，罩顶以上留足净空后允许飞越。

## 4. 实现保持简单

一个主场景，少量脚本即可：

- **飞行控制**：自动航线和手动驾驶。
- **安全控制**：岛内保护、海面限制和外边界。
- **镜头控制**：跟随、自由观察和缩放。
- **界面控制**：按钮、状态提示、暂停和退出。
- **统一复位**：让每次展示都能回到同一个可靠起点。

先用简化岛和代理飞机调通这些功能。用户提供香港岛和 J-20 模型后，在同一个 DEMO 中接入，检查比例、朝向、保护范围和镜头即可。模型替换只是制作过程，不是另做一个版本。

不做多人、武器、任务系统、天气昼夜、复杂设置、通用资产加载系统或预留扩展架构。小地图、地标介绍等也不列为必做。

## 5. 展示重点与完成标准

把时间优先花在：**开场构图、平滑飞行、镜头手感、场景光照、简洁 UI，以及现场不出故障。**

建议准备一段约两分钟的演示：先自动环岛展示画面，再自由观察、解锁驾驶，最后演示保护和复位。

完成标准只有三条：

1. 核心操作能连续演示，观众容易理解。
2. 不穿楼、不坠海、不越界失控，复位始终可靠。
3. 接入本次模型后，在展示电脑上画面流畅、无明显错误。

最终交付就是这一个可运行的展示 DEMO，附简短操作说明；录屏可作为现场演示的备份。

## 主要入口

工程：`<PROJECT_ROOT>\My project (1)`。
场景：`Assets\_FlightDemo\Scenes\HKFlight_Demo.unity`（相对此工程根目录）。

| 文件（位于工程 Assets/_FlightDemo 内） | 接手时看什么 |
|---|---|
| Scripts/FlightController.cs | 飞行状态、自动/手动、唯一位姿提交和复位 |
| Scripts/DemoSafety.cs | 保护体、连续包络查询、海面/边界参数 |
| Scripts/DemoRoute.cs | 当前椭圆航线、采样、速度进度 |
| Scripts/DemoOrbitCamera.cs | 跟随、观察、缩放和复位 |
| Scripts/DemoHUD.cs | 按钮、快捷键、模态窗口和 HUD |
| Editor/FlightDemoAssetIntegrator.cs | PBR 模型接入、保留导入轴向并重算机体中心 |
| Editor/FlightDemoChecks.cs | 读取实际场景尺寸的有限检查；UI 部分是跨帧运行 |

已接入模型后不要重复运行“Create Placeholder Scene”或“Integrate PBR Island and J-20”。
UI 的生成是 DemoHUD 在 Play 时完成，修改 UI 应修改该脚本，不要将运行中的临时 Canvas 保存回编辑场景。
